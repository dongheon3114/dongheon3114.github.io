# 나의 기록장

GitHub Pages + Jekyll로 만든 개인 블로그입니다.

## 처음 할 일
1. `_config.yml`을 열어 `title`, `description`, `author`, `url`을 내 정보로 바꾸기
2. `about.md`에 자기소개 쓰기

## 글 쓰는 법
| 쓰고 싶은 것 | 넣을 폴더 | 파일 이름 예시 | 맨 위에 적을 것 |
|---|---|---|---|
| 일기 | `_posts` | `2026-11-05-rainy-day.md` | `categories: diary` |
| 생각 | `_posts` | `2026-11-05-on-reading.md` | `categories: thoughts` |
| 책의 한 장 | `_book` | `02-chapter-two.md` | `chapter: 2` |

`_templates/새글-템플릿.md`를 복사해서 쓰면 편해요.
파일 이름은 영문·숫자·하이픈으로 쓰는 게 안전합니다 (제목은 한글로 써도 됩니다).
